# #149 [Bug] Cannot assign Ctrl+Alt+Del shortcut

> *This was generated by AI during triage.*

**State:** wontfix

## Root cause (Mouser evidence)

- Ctrl+Alt+Del is the Secure Attention Sequence (SAS). Winlogon handles it, not the keyboard input queue, so a user-mode app can neither capture it with a hook nor synthesize it with `SendInput`.
- The reference already treats it as unreliable: `core/key_registry.py:53-61` lists `("ctrl", "alt", "delete")` in `RESERVED_RISKY_SHORTCUTS`; `is_reserved_risky_shortcut` is at `core/key_registry.py:302`; the capture dialog shows a warning (`ui/qml/KeyCaptureDialog.qml:119`, string `key_capture.reserved_warning` at `ui/locale_manager.py:238`) but still allows saving.
- Not located: any code that could make an injected Ctrl+Alt+Del work. By the Windows security model none can exist.

Confidence: confirmed (platform limitation).

Decision: wontfix as requested. The suggested alternative (a dedicated action) is a separate enhancement; working neighbours are lock workstation (`LockWorkStation()`) or launching Task Manager (`taskmgr.exe`).
