Nothing installs `faulthandler` or a crash log (grep of `main_qml.py`, `core/log_setup.py`: no match), so a native crash in a Python/Qt/hidapi thread would leave no trace. The "faster when minimized" detail fits a native crash or an OS-side kill while the window is hidden, but that is a guess.
- Separate point worth carrying forward: the Windows low-level mouse hook is silently removed by the OS if its callback is too slow. Mouser has no health check (`core/mouse_hook_windows.py:663` installs once; `_reinstall_hook` at `:710` runs only on device-change). That would cause remapping to stop, not an exit.

Confidence: guess.
