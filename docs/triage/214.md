# #214 [Bug] MX Anywhere 3 does not have smart shift setting when auto-detect or choose "MX anywhere family"

> *This was generated by AI during triage.*

**State:** `ready-for-agent`

## Root cause (Mouser evidence)

- `ui/qml/ScrollPage.qml:295,299` show the SmartShift section only if `backend.smartShiftSupported && backend.deviceHasSmartShift`.
- `ui/backend.py:633-637` `deviceHasSmartShift` is true only when `"mode_shift"` is in the effective supported buttons. So the setting is gated on a physical mode-shift button, not on the HID++ SmartShift feature (0x2110/0x2111) that MX Anywhere 3 exposes (`smart_shift_supported` at `core/hid_gesture.py:1997-1999`; the #209 device JSON for MX Anywhere 3 lists `SMART_SHIFT_ENHANCED (0x2111)`).
- Manual "MX Anywhere family" override: `ui/backend.py:2474-2478` uses `get_buttons_for_layout(override_key)` (`core/logi_devices.py:827-834`), which for `mx_anywhere` returns `MX_ANYWHERE_BUTTONS` (`core/logi_devices.py:41-50,821`), a tuple without `mode_shift`. Hence the setting disappears. Confirmed.
- Auto-detect: catalog entries for MX Anywhere 3/3S use `MX_ANYWHERE_SMARTSHIFT_BUTTONS` (`core/logi_device_catalog.py:68-71,279`), but `supported_buttons` drops `mode_shift` when the capability flag is false (`core/logi_devices.py:318-319`). The #209 JSON for the same device (v3.6.0) has no `mode_shift` in `supported_buttons` even though CID 0x00C4 is listed; why was not located (older build or another filter).

Confidence: confirmed for the family-override path; likely for the auto-detect path.

## Agent Brief

**Category:** bug
**Summary:** SmartShift/MagSpeed settings must be shown whenever the device exposes the SmartShift HID++ feature, independent of a mode-shift button or a manual layout override.

**Current behavior:**
MX Anywhere 3 shows no SmartShift setting under auto-detect or with the "MX Anywhere family" layout. It appears only when the MX Master family is forced.

**Desired behavior:**
The SmartShift panel and its ratchet / free-spin / threshold controls are available if and only if the connected device reports feature 0x2110 or 0x2111. The "Toggle SmartShift" button action is offered only if the device also has a mode-shift button. Manual layout overrides affect only button images and hotspots, never feature availability.

**Key interfaces:**
- Device capability struct: `smart_shift: bool` from HID++ discovery, separate from the button set.
- GUI visibility predicate for the SmartShift panel.
- Layout override: must not alter `smart_shift`.

**Acceptance criteria:**
- [ ] Unit test: capabilities with feature 0x2111 and no CID 0x00C4 give `smart_shift == true` and no `mode_shift` button.
- [ ] Unit test: applying the generic anywhere-family override to a device with `smart_shift == true` keeps the panel visible.
- [ ] Unit test: a device without 0x2110/0x2111 hides the panel regardless of layout.
- [ ] Manual: MX Master 2S (has SmartShift) shows the panel.

**Out of scope:**
- MX Anywhere artwork
- Mode-shift button remapping when the button does not exist
